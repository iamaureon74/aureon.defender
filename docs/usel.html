research alpha · 0.1.1

write it once.
in every language you actually have.

usel is a small language and compiler for international seo.
it’s how we’d like our apps to be found — carefully, not loudly.

01 / author

one source file.

each page lists its real translations — title, description, text and address per language. private pages stay out of every output, always.

02 / compile

plain, correct html.

every language version points to the others (hreflang), says which way its text runs, and sits in a sitemap and a home page that links them all.

03 / check

an audit before you ship.

the compiler re-reads what it wrote: canonical links, reciprocal languages, sitemap entries, noindex rules. if anything doesn’t line up, it says so.

04 / research

each engine, on its own terms.

a registry of 50 search services and 250 countries and territories. only 15 engines have a cited source so far; everything else stays marked unknown.

how it fits together

from one file
to a crawlable site.

nothing is sent anywhere unless you ask.
indexnow pings are opt-in and need a key you host.

source

a .usel file

yaml or json: site name, https address, pages, locales, optional default language and indexnow key. strict checks reject unsafe paths and private pages marked indexable.

output

static files

html per language, a home hub, robots.txt, sitemap(s), a country-by-country coverage report, an engine guide and an offline indexnow plan.

evidence

sources, dated

google, bing, yandex, naver, seznam, baidu, sogou, 360, brave, mojeek, duckduckgo, ecosia, yep and two crawlers have a cited document; the rest are research leads.

what it can’t do

no ranking promises.
no tricks.

search engines keep most of their rules private,
and change them often.

not included

translation or keywords

you still need real local-language content. usel won’t translate, invent demand, or keyword-stuff.

not verified

indexing or traffic

a valid sitemap isn’t proof a page is indexed. check each engine’s own webmaster tools after you publish.

not complete

every engine on earth

there’s no permanent list of all search services. the registry grows one cited source at a time, and unknown stays unknown.

run it locally: python -m usel compile examples/bosley.usel.yaml --output build then python -m usel audit build. the development server is for your own computer only. read the source and the evidence notes ↗
