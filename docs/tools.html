release checksums · source code and platform scope

keep what matters.
every version, on this device.

add files and they are kept in this browser's own storage. identical bytes are stored once, each change becomes a version, and a file only comes back if its fingerprint still matches. nothing is uploaded.

iphone and ipad do not let any app, this one included, watch your files or run in the background, and there is no way to install python on them. so here you choose what to keep. add this page to your home screen: safari can clear storage of sites you haven't opened in a while, but not of home-screen apps. on android and computers the installed app keeps your folders on its own.

remove hidden details.
right here, on this device.

choose photos, songs or pdfs. common details like location, camera model and serial, author, dates and comments are removed inside this browser, and you save a clean copy. nothing is uploaded. photos keep their orientation. it should work on iphone, ipad, android, mac, linux and chromeos without installing anything.

    a web page can only clean the files you pick. automatic cleaning and silent malware removal happen in the windows, android and mac/linux apps. anything visible in the file — faces, watermarks, text — stays as it is.

    Platform editions differ

    Windows has the broadest host integration. Android is sandboxed. macOS/Linux portable builds offer read-only posture checks and local file/hash tools. This web edition offers local metadata cleaning, file/hash matching and report reading.

    Privacy

    There are no analytics, advertising libraries, accounts or data-upload endpoints in this web edition. Visiting GitHub downloads uses GitHub's services and policies. Imported hash lists stay in memory and clear when this page is closed. The service worker caches application assets, never selected files or report contents.

    Availability

    No country-based restriction is implemented in this code. Network access, browser/OS support and distribution availability can vary. English interface; Unicode file/report text is supported. No promise of every device or country is made.
