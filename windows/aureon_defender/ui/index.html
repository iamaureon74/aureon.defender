A closer look starts here.
Choose files or a folder. Results identify which scanning layers actually ran.


Strip metadata layers
Creates separate copies with selected known metadata fields removed. JPEG/PNG/WebP/GIF, MP3/FLAC/WAV, Office/OpenDocument, PDF and MP4/MOV have different coverage. PDF cleanup is partial. HEIC and multi-page images are not batch-cleaned. Visible names, watermarks, embedded content and all fingerprints cannot be guaranteed removed. Originals are kept. Up to 128 MiB/file and 2,000 files/batch. Also covers SVG, Ogg/Opus, AIFF, MKV/WebM and ZIP; HEIC/AVIF become JPEG copies when an image plug-in is installed. Every download also loses the website/page address Windows records about it (the safety zone stays).






Find leaked keys
Checks code, notes and documents for 220 kinds of passwords, API keys and tokens, card numbers and wallet phrases, and tells you what to do about each.




Password breach check
